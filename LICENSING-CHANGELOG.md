# Licensing Changelog

All dates use ISO 8601 calendar dates. This log records repository licensing changes; it does not alter rights already granted to recipients of earlier distributions.

## 2026-11-25 — Apache-2.0 adoption

### Changed
- Adopted the standard Apache License, Version 2.0 (SPDX: `Apache-2.0`) for the RIGOR-X repository Work, subject to confirmation of rights for every included contribution and third-party component.
- Replaced the proprietary source-available root notice with the complete Apache-2.0 license text.
- Replaced the proprietary commercial licensing policy with an open-source scope and contribution policy.
- Updated README, contributor guidance, public review guidance, release checklist, changelog, and Python package metadata.
- Added NOTICE and a separate trademark policy.
- Removed the active commercial subscription agreement and deployment addenda from the current repository policy set. Optional Aetherica services remain independent of the open-source grant.

### Superseded historical policy
Earlier on 2026-11-25, the repository contained a proprietary, source-available Commercial Subscription License (CSL) framework. That policy is superseded for the current repository Work by the Apache-2.0 adoption commit. Copies and distributions made before that commit remain subject to the terms that applied to those copies, unless their respective rights holders separately relicense them.
