# Changelog

## 0.1.0 — 2026-11-25

- Established the initial 999-entry slash-token research library.
- Added 17 functional groups and stable `SLC-0001` … `SLC-0999` IDs.
- Added standalone manifest, canonical JSON dataset, CSV export and group catalogue.
- Added both command-entry and complete-library JSON Schemas.
- Added JSON Schema Draft 2020-12 command-entry schema.
- Added provenance register, engineering standard, validator and validation record.
- Recorded platform/native, UI/menu, macro, alias and image-keyword distinctions.
- Runtime status for every entry is `not_implemented_in_rigor_x`; lifecycle status is `candidate`.
- Command-level source verification, alias review, JSON Schema engine execution, Python validator execution and CI remain pending.

## 0.2.0 — 2026-11-25

- Corrected the functional taxonomy from 17 to 18 groups.
- Added Finance, business & investment (7 entries).
- Reclassified `/roi`, `/budget`, `/finances`, `/marketmap`, `/businessmodel`, `/pitch` and `/investor`.
- Preserved all 999 records and stable IDs.
- Expanded validation to Draft 2020-12 schema checks and complete CSV/JSON field parity.
- Added GitHub Actions CI using stable Python 3.15.
- Recorded latest-stable-runtime policy; source-level and semantic command verification remains open.
