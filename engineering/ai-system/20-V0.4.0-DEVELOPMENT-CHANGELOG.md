# RIGOR-X 0.4.0 Development Changelog

Status: **0.4.0.dev0 — not a final release**

## Implemented and CI-verified
- Fail-closed command execution framework with capability/approval gates and safe receipts.
- Model-agnostic bounded tool-call runtime and actual OpenAI-compatible HTTP backend.
- Runnable `rigorx-agent` text CLI and `rigorx-version` CLI.
- Slash command catalogue validation and prompt-level execution for 909/999 MACRO, MACRO ALIAS and IMAGE KEYWORD records; canonical alias precedence.
- Native/UI/platform commands preserved and marked host integration required (90 entries).
- Six-level adaptive heuristic router and explicit level overrides.
- Optional bounded contextual activation across 36 historical knowledge domains; status/provenance preserved.
- Model endpoint security checks, response-size cap, transport redaction.
- CI immutable action pins, Python 3.13/3.15 matrix, Ruff, 130 tests, wheel/sdist builds and installed-wheel checks.

## Not included / release blockers
- Final release/tag.
- Live API acceptance with real credential/provider.
- ChatGPT/plugin host connector implementation and integration.
- Operational handlers/adapters for all 999 commands (particularly 90 native/UI/platform).
- Fully recovered and owner-ratified 30 formulas, 33 algorithms, 111 topics, 15 operators and 18 FG ownership definitions.
- Research acquisition, durable knowledge/memory backends, evidence/provenance system and full system evaluation.

No fake, dummy or placeholder functionality is counted as implemented.


## Additional increment: AgentPipeline
- 11-stage pipeline execution wrapper for model/tool runs.
- SQLite persistence for snapshots and events, stage artifacts, evidence IDs/hashes.
- Privacy-minimized ledger; raw prompts and raw tool outputs excluded.
- Deterministic fail-closed verification prevents DECISION for blocked actions or research without successful source-acquisition receipts.
- CLI is now pipeline-backed and persistent by default.
- Acceptance: 135 tests PASS on Python 3.13/3.15; Ruff, wheel/sdist build and wheel installation checks PASS.


## Adaptive analysis mode routing
- Added 12 adaptive method modes to each task profile, with multi-mode signal selection and intent defaults.
- Modes are transparent heuristics and remain overrideable/refinable by host model; no semantic accuracy claim.
- CI: 136 tests PASS, Ruff and distribution/wheel validation PASS on Python 3.13 and 3.15.
